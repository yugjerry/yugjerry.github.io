# Homepage Chinese name font

`name.woff2` is the regular (400) LXGW WenKai TC webfont subset for 桂昱
(U+6842 and U+6631), served locally with the site. The file is 1,496 bytes.

- Upstream: https://github.com/lxgw/LxgwWenkaiTC
- Google Fonts distribution: https://github.com/google/fonts/tree/main/ofl/lxgwwenkaitc
- Subset obtained on 2026-09-26 from the Google Fonts CSS API, requesting
  `family=LXGW WenKai TC`, `text=桂昱`, and `display=swap`.
- License: SIL Open Font License 1.1; see the accompanying `OFL.txt`.

The CSS family alias is `LXGW WenKai TC Name`. The original font data has not
been edited locally. If the displayed Chinese name changes, obtain a new
subset covering the new characters and update the CSS `unicode-range`.
